# Vasudev rebrand — surface rename and the orb

Owner decisions (2026-09-14): replace every **user-visible** "OpenClaw" with **"Vasudev"** and keep everything else the same (taglines and sentences keep their wording with the name swapped — "All your chats, one Vasudev.", "Ask Vasudev", "Message Vasudev…", "Vasudev Control", "Vasudev access approved"); the maker line where a product title exists is **"Vasudev · by TripIn Studio"**; the Telegram assistant label becomes **"Vasudev"**; the logo everywhere is the **Vasu orb** (the `/vasudev-brand` guide's orb) instead of the lobster marks. **Internals stay `openclaw`** — npm package names, the `openclaw` binary (a `vasudev` alias is added), config keys, `~/.openclaw`, plugin ids, Gateway method names, env vars, service labels (`openclaw-gateway`, `ai.openclaw.gateway`, `_openclaw-gw._tcp`), process titles, Docker image names — so upstream `openclaw/openclaw` keeps merging. A later phase applies the full visual theme (tokens, type) from `/vasudev-brand`; this spec is the name and the mark only.

## 2. Mechanism

- `src/brand.ts`: `PRODUCT_NAME = "Vasudev"`, `MAKER_LINE = "Vasudev · by TripIn Studio"`, `CLI_ALIASES = ["openclaw", "vasudev"]`, `TAGLINE = "All your chats, one Vasudev."`; every TypeScript surface in §1 imports it (no literal "Vasudev" outside the module and docs).
- `ui/src/app/brand.ts`: the same constants for the Control UI; `index.html`/manifest receive them at build time (Vite `define`/HTML transform) so the static files stay in sync; the English locale keys reference the constant where the i18n system allows interpolation, else they are literal and covered by a test that scans `en*.ts` for the old name.
- **Guard**: `scripts/check-brand.mjs` (added to the `check-changed` lanes for the changed files) fails when a user-visible file (allowlisted globs: `ui/src/**`, `src/cli/**`, `src/wizard/**`, `docs/**/*.md`, `README.md`, `extensions/*/openclaw.plugin.json`, the templates) contains a word-boundary "OpenClaw" that is not a known identifier (`OpenClawConfig`, `OpenClawPluginApi`, `openclaw.plugin.json`, URLs to `openclaw/openclaw` or `docs.openclaw.ai`, env `OPENCLAW_*`, `~/.openclaw`), and when any product surface (banner, manifest, pairing message, sender label) does not read the brand module. The replacement itself is done by `scripts/rebrand-apply.mjs` (idempotent, re-runnable after upstream merges) over the same allowlist with the same identifier exclusions.
- **Orb assets**: `assets/brand/orb.svg` (static master: gradient circle, highlight, glow — from `/vasudev-brand`), generated `favicon.svg/ico/32.png`, `apple-touch-icon.png`, docs logo (`docs/assets/orb.svg`), hero/banner PNGs replaced by an orb-on-paper composition; a Lit/CSS `<vasu-orb>` element for the login gate and sidebar (animated `hue` + `breathe`, static under reduced motion). No image tooling dependency is added: PNG/ICO generation runs through the browser plugin's managed Chromium screenshot of the SVG (a small script) or is committed as generated assets — implementer's choice, recorded.
- **Tests**: banner/tagline/document-title/terminal/e2e expectations updated in lockstep; new `check-brand` test fixtures (an offending file fails; identifiers pass).

## 3. Phases
